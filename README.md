# DriverUpdater

**Бесплатная программа, которая сама находит и ставит нужные драйверы для вашего компьютера.**

Вы запускаете программу — она смотрит, что стоит внутри компьютера (видеокарта, сеть, звук, Bluetooth и всё остальное), проверяет, у каких устройств нет драйвера или есть более новый, и объясняет простыми словами, что из этого действительно нужно. Остаётся нажать одну кнопку.

## Скачать

👉 **[Скачать последнюю версию](https://github.com/Miffk/DriverUpdater/releases/latest)** — на странице нажмите на файл **`DriverUpdater.exe`**.

Устанавливать ничего не нужно: просто запустите скачанный файл.
Работает на **Windows 10 и Windows 11** (64-бит).

## Как пользоваться

1. **Запустите `DriverUpdater.exe`.** Windows спросит разрешение на изменения — нажмите «Да»: без этого Windows не даёт ставить драйверы.
2. **Подождите 1–3 минуты.** Программа сама определит оборудование и поищет драйверы.
3. **Посмотрите результат.** Все устройства разложены по группам:
   - 🔴 **Необходимо** — устройство не работает или работает плохо. Это стоит поставить.
   - 🟠 **Рекомендуется** — всё работает, но есть полезное обновление (например, новый драйвер видеокарты).
   - 🔵 **Необязательно** — можно пропустить, польза небольшая.
   - 🟢 **В порядке** — ничего делать не нужно.

   Нажмите на любое устройство — программа объяснит, **почему** ему нужен (или не нужен) драйвер.
4. **Нажмите «Установить».** Нужное уже отмечено. Программа скачает драйверы, установит их и удалит скачанные файлы.
5. Если программа попросит — **перезагрузите компьютер**.

## Откуда берутся драйверы

Только с **официальных сайтов**:

- **Microsoft** (Windows Update и каталог драйверов Microsoft) — туда производители выкладывают проверенные драйверы;
- **NVIDIA** — свежие драйверы видеокарт GeForce в день выхода;
- **AMD и Intel** — их собственные бесплатные программы для подбора драйверов (программа скачает и запустит их за вас).

Каждый файл перед установкой проверяется по цифровой подписи производителя. Сомнительные «сборники драйверов» и неофициальные сайты не используются.

Если драйвера нет ни у одного из этих источников, программа покажет кнопку **«Сайт производителя»** или **«Найти драйвер»** — поиск будет идти только по официальному сайту производителя устройства.

## Если устройство работает с ошибкой

Иногда драйвер стоит правильный, но устройство «зависло» (так бывает с USB-устройствами, подсветкой, геймпадами). Тогда программа так и напишет и предложит кнопку **«Исправить»** — она перезапустит устройство, как будто вы вынули его и вставили обратно.

## Безопасно ли это

- Перед установкой программа создаёт **точку восстановления Windows** — если что-то пойдёт не так, всё можно вернуть (Пуск → «Восстановление» → «Запуск восстановления системы»).
- **Прошивки BIOS** программа сама никогда не ставит: это может быть опасно, если во время обновления пропадёт питание.
- После установки **все скачанные файлы удаляются** — место на диске не пропадает.

## Обновление программы

Когда выходит новая версия, вверху окна появится надпись **«Вышла новая версия»** — нажмите **«Обновить»**, и программа обновится сама.

## Частые вопросы

**Windows пишет «Система Windows защитила ваш компьютер».**
Так Windows реагирует на новые программы без платного сертификата издателя. Нажмите **«Подробнее» → «Выполнить в любом случае»**.

**Антивирус ругается на программу.**
Иногда антивирусы по ошибке реагируют на программы, собранные из Python. Программа открытая — весь её код лежит здесь, на GitHub.

**Программа не открывается и просит установить WebView2.**
Это бесплатный компонент Microsoft, которым рисуется окно программы. Он есть во всех обновлённых Windows 10 и 11. Согласитесь — программа скачает его с сайта Microsoft сама.

**Нужно ли подключение к интернету?**
Да — драйверы скачиваются из интернета.

**Программа ничего не нашла, а производитель пишет, что есть новый драйвер.**
Нажмите на устройство и выберите **«Сайт производителя»** — там самая свежая версия. Напишите нам об этом в [Issues](https://github.com/Miffk/DriverUpdater/issues), чтобы мы научили программу находить такие драйверы.
