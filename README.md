# DriverUpdater

Программа для Windows 10/11, которая:

1. **Определяет конфигурацию ПК**: модель, материнская плата, BIOS, процессор, память, видеокарты, ОС, а также все устройства и установленные на них драйверы (версия, дата, производитель).
2. **Решает, что делать с каждым драйвером**: установить, обновить или оставить как есть, и делит их на группы *необходимо / рекомендуется / необязательно / не требуется*. Для каждого устройства пишет причину.
3. **Ищет драйверы только в официальных источниках Microsoft**: Windows Update и Microsoft Update Catalog. Туда производители (NVIDIA, AMD, Intel, Realtek и др.) выкладывают драйверы, прошедшие сертификацию WHQL.
4. **Скачивает и устанавливает** их, перед этим создаёт точку восстановления и проверяет цифровую подпись.
5. **Удаляет установочные файлы** после установки, даже если установка завершилась ошибкой.

## Запуск

Нужен Python 3.10 или новее. Сторонние библиотеки не нужны, программа использует только стандартную библиотеку Python и встроенные средства Windows (PowerShell, WMI, Windows Update Agent, `pnputil`, `expand`).

```bat
:: 1. Только посмотреть железо и драйверы (без интернета)
python -m driverupdater scan

:: 2. Найти, что нужно установить/обновить, и узнать почему
python -m driverupdater check

:: 3. Посмотреть план установки, ничего не устанавливая
python -m driverupdater install --dry-run

:: 4. Установить (запускать от имени администратора)
python -m driverupdater install
```

Можно просто дважды щёлкнуть `DriverUpdater.bat`: он сам запросит права администратора и запустит установку с подтверждением.

### Полезные ключи

| Ключ | Что делает |
|---|---|
| `--all` | показать все устройства, включая те, где всё в порядке |
| `--json` | вывод в JSON (для интеграции с другими программами) |
| `--deep` | искать в каталоге обновления для всех важных устройств, а не только для проблемных (дольше) |
| `--include-optional` | ставить и необязательные драйверы |
| `--allow-firmware` | разрешить обновления прошивок BIOS/UEFI (по умолчанию никогда не ставятся автоматически) |
| `--backup-dir DIR` | перед установкой сохранить копию текущих драйверов (`pnputil /export-driver`) |
| `--skip-restore-point` | не создавать точку восстановления |
| `-y` | не спрашивать подтверждения |
| `--save FILE` / `--from-file FILE` | сохранить снимок железа в файл или загрузить его из файла (для отладки и тестов) |

## Как программа решает, что нужно

| Группа | Когда | Пример объяснения |
|---|---|---|
| **НЕОБХОДИМО** | Устройство не работает из-за драйвера: в Диспетчере устройств ошибка с кодом 28, 10, 18, 31, 43, 52 и т.п. Или видеокарта работает на «Базовом видеоадаптере Microsoft» | «Видеокарта работает на базовом адаптере: нет аппаратного ускорения, игр, нормальной частоты обновления» |
| **РЕКОМЕНДУЕТСЯ** | Вышла новая версия драйвера для видеокарты, сети, Bluetooth или чипсета. Или вместо драйвера производителя стоит универсальный драйвер звука | «Сетевой драйвер напрямую связан с безопасностью и стабильностью подключения» |
| **НЕОБЯЗАТЕЛЬНО** | Устройство работает, а обновление даёт мало: звук, камера, контроллер дисков, USB, надстройки производителя, прошивки | «Работающий драйвер контроллера дисков лучше не менять без причины, от него зависит загрузка Windows» |
| **НЕ ТРЕБУЕТСЯ** | Драйвер в порядке, новее нет. Или используется стандартный драйвер Windows, и для этого класса устройств он правильный (USB, клавиатура, мышь, монитор) | «Используется стандартный драйвер Windows — это правильный выбор» |

Новизна определяется так же, как это делает сама Windows: сначала сравнивается дата драйвера, а при равной дате — номер версии.

По умолчанию ставятся только группы «необходимо» и «рекомендуется». Прошивки не ставятся никогда, если не указан `--allow-firmware`. Порядок установки: сначала чипсет, затем контроллеры дисков, видеокарта и сеть. Так советуют производители.

## Откуда берутся драйверы и как они удаляются

| Источник | Как ставится | Как удаляются файлы |
|---|---|---|
| **Windows Update** (официальный API Windows Update Agent) | Windows сама скачивает и устанавливает драйвер | После установки программа удаляет из `C:\Windows\SoftwareDistribution\Download` только пакеты, скачанные за время её работы |
| **Microsoft Update Catalog** (поиск по Hardware ID). Используется для устройств, которым Windows Update ничего не предложил | `.cab` скачивается во временную папку `%TEMP%\DriverUpdater_*`, распаковывается и ставится через `pnputil /add-driver /install` | Временная папка удаляется в блоке `finally`, то есть и при ошибке. Объём удалённого программа выводит в конце |

Меры безопасности:
- файлы скачиваются только с доменов Microsoft (`*.download.windowsupdate.com`, `download.microsoft.com`), остальные отклоняются;
- перед установкой проверяется подпись Authenticode: архив или файлы `.cat` внутри него должны быть подписаны Microsoft (WHQL). Неподписанные пакеты не ставятся;
- перед установкой создаётся точка восстановления системы, по желанию ещё и резервная копия текущих драйверов;
- сторонние «драйверпаки» и неофициальные сайты не используются.

Для видеокарт NVIDIA, AMD и Intel программа дополнительно показывает ссылку на официальный сайт производителя: там версии обычно новее, чем в каталоге Microsoft.

## Структура

```
driverupdater/
  hardware.py              определение железа и драйверов (WMI/CIM через PowerShell)
  classify.py              правила «необходимо / рекомендуется / необязательно» и объяснения
  versions.py              сравнение версий и дат драйверов
  providers/windows_update.py  поиск, установка, очистка кэша через Windows Update Agent
  providers/catalog.py     поиск и скачивание из Microsoft Update Catalog
  installer.py             точка восстановления, скачивание, проверка подписи, pnputil, удаление файлов
  report.py, cli.py        вывод и командная строка
tests/                     тесты на снимке реального ПК (запускаются на любой ОС)
```

Тесты: `python -m unittest discover -s tests -t .`

Собрать один `.exe` без установки Python: `pip install pyinstaller && pyinstaller --onefile --uac-admin -n DriverUpdater driverupdater/__main__.py`

## Ограничения и планы

- Программа работает только на Windows. На других ОС доступен режим `--from-file`, он нужен для тестов.
- Microsoft Update Catalog не имеет официального API, поэтому разбирается его веб-страница. Если Microsoft изменит вёрстку, поиск в каталоге придётся поправить. Windows Update от этого не зависит.
- Фирменные установщики производителей (`.exe` с панелями управления вроде NVIDIA App или AMD Adrenalin) пока не скачиваются. Программа даёт ссылку на официальную страницу. Следующий шаг — модули для NVIDIA, AMD и Intel с их официальными сервисами поиска драйверов.
- Возможная графическая оболочка: список устройств с галочками и пояснениями.
