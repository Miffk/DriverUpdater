## Что нового в версии 0.3.3

- **Надёжная проверка обновлений.** Раньше программа спрашивала о новой версии через сервис GitHub, у которого есть лимит запросов: если много людей выходят в интернет через один адрес провайдера, проверка могла не сработать. Теперь программа смотрит обычную страницу релизов — без лимитов.
- Всё из версии 0.3.2: кнопка «Обновить» работает и во время поиска драйверов, видно скачивание обновления с процентами, понятные ошибки.

**Если у вас версия 0.3.0 или 0.3.1:** дождитесь, пока закончится поиск драйверов (в шапке появится «Проверка завершена»), и только потом нажмите «Обновить» один раз. Или скачайте `DriverUpdater.exe` ниже.
