## Что нового в версии 0.3.0

- **Свежие драйверы NVIDIA** — программа проверяет новую версию прямо на сайте NVIDIA, а не только в Windows Update (там новые драйверы появляются позже).
- **Больше драйверов от Microsoft** — каталог драйверов Microsoft теперь проверяется для всех важных устройств, а не только для сломанных.
- **AMD и Intel** — кнопка, которая скачивает и запускает официальную программу производителя для подбора драйверов.
- **Кнопка «Исправить»** — если драйвер правильный, но устройство зависло (например, USB-устройство с ошибкой), программа перезапустит его.
- **Сайт производителя** — если драйвера нет у Microsoft, программа покажет официальный сайт производителя и поиск по нему.
- **Видны все устройства** — список показывает все драйверы, группы можно сворачивать.
- **Понятные названия** — «MSI» вместо «Micro-Star International Co., Ltd.», «Windows 11 Pro 25H2 · 64-бит» вместо номера сборки, понятные названия устройств.
- **Все объяснения переписаны простыми словами.**
- **Обновление программы прямо из окна** — когда выйдет новая версия, вверху появится кнопка «Обновить».

**Как скачать:** нажмите на файл `DriverUpdater.exe` ниже и запустите его.
