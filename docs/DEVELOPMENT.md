# DriverUpdater — для разработчиков

Описание для пользователей — в [README](../README.md). Здесь: как устроена программа, как её запускать из исходников, тестировать и выпускать новые версии.

## Источники драйверов

| Источник | Что даёт | Как ставится |
|---|---|---|
| Windows Update (Windows Update Agent API) | драйверы, которые Windows сама считает подходящими | Windows скачивает и ставит; потом удаляем скачанное из `SoftwareDistribution\Download` |
| Microsoft Update Catalog (поиск по Hardware ID) | все драйверы, опубликованные у Microsoft, в том числе не предлагаемые автоматически | `.cab` → проверка подписи → `pnputil /add-driver /install` → удаление |
| Сайт NVIDIA (`lookupValueSearch` + `AjaxDriverService`) | свежий Game Ready в день выхода | exe с `us.download.nvidia.com` → подпись NVIDIA → `-s -noreboot` → сверка версии в WMI → удаление |
| Официальные программы AMD и Intel | AMD Software Auto-Detect, Intel Driver & Support Assistant | скачать с сайта производителя → подпись → запуск (пользователь проходит мастер) → удаление |
| Сайт производителя / поиск | для остальных: страница драйверов и поиск только по официальному домену | вручную |

Если драйвер правильный (стандартный драйвер Windows), но устройство сбоит (коды 10, 43 и т.п.) — предлагается перезапуск устройства: `pnputil /restart-device`, при неудаче `/remove-device` + `/scan-devices`.

Названия моделей берутся из открытых баз [pci.ids](https://pci-ids.ucw.cz/) и [usb.ids](http://www.linux-usb.org/usb.ids) — они скачиваются при сборке в `driverupdater/data/` (в git не хранятся).

## Обновление программы

`updater.py` проверяет `releases/latest` на GitHub, скачивает новый exe, сверяет SHA-256 (поле `digest` ассета GitHub или `SHA256SUMS.txt`), переименовывает запущенный exe в `.old`, кладёт новый на его место и перезапускает. `.old` удаляется при следующем запуске.

Выпуск версии: поднять `__version__` в `driverupdater/__init__.py` (и `pyproject.toml`, `packaging/version_info.txt`), обновить `RELEASE_NOTES.md` и отправить коммит в основную ветку. GitHub Actions соберёт exe и, если релиза `vX.Y.Z` ещё нет, сам создаст тег и опубликует релиз с `DriverUpdater.exe`, `DriverUpdater-cli.exe` и `SHA256SUMS.txt`. Можно и вручную поставить тег `vX.Y.Z` — тогда сборка проверит, что он совпадает с версией.

## Запуск из исходников

Нужен Python 3.10 или новее. Консольной версии сторонние библиотеки не нужны: она использует только стандартную библиотеку Python и встроенные средства Windows (PowerShell, WMI, Windows Update Agent, `pnputil`, `expand`). Графической версии нужен pywebview (`pip install pywebview`), запуск: `python -m driverupdater.webui`.

## Интерфейс

Окно сделано на **pywebview + HTML/CSS**: интерфейс рисует компонент Windows **Edge WebView2**. Он встроен в Windows 11 и в обновлённую Windows 10. Если его нет (например, на свежей Windows 10 со старого образа), программа предложит скачать официальный установщик Microsoft, проверит его подпись, установит и удалит.

Что есть в окне:
- кольцо «состояния драйверов» и короткий вывод: что нужно сделать;
- карточки компьютера: модель, процессор, видеокарта, память, плата, Windows;
- сводка по группам «Необходимо / Рекомендуется / Необязательно / В порядке» (нажатие фильтрует список);
- список устройств с производителем и версиями «сейчас → будет»; по нажатию раскрывается объяснение;
- поиск по названию, производителю, ID оборудования и названию драйвера;
- экран установки с прогрессом по каждому драйверу, итогом, объёмом удалённых файлов и кнопкой перезагрузки;
- светлая и тёмная тема (переключаются вместе с Windows), раскладка подстраивается под экраны от ноутбука 1366×768 с масштабом 125% до 4K.

Посмотреть интерфейс без Windows можно в браузере с подставными данными: `tests/ui/mock_api.js` (задаёт `window.pywebview.api` и воспроизводит события из `window.__FIXTURE__`).

```bat
:: 1. Только посмотреть железо и драйверы (без интернета)
python -m driverupdater scan

:: 2. Найти, что нужно установить/обновить, и узнать почему
python -m driverupdater check

:: 3. Посмотреть план установки, ничего не устанавливая
python -m driverupdater install --dry-run

:: 4. Установить (запускать от имени администратора)
python -m driverupdater install
```

Можно просто дважды щёлкнуть `DriverUpdater.bat`: он сам запросит права администратора и запустит установку с подтверждением.

### Полезные ключи

| Ключ | Что делает |
|---|---|
| `--all` | показать все устройства, включая те, где всё в порядке |
| `--json` | вывод в JSON (для интеграции с другими программами) |
| `--deep` | искать в каталоге обновления для всех важных устройств, а не только для проблемных (дольше) |
| `--include-optional` | ставить и необязательные драйверы |
| `--allow-firmware` | разрешить обновления прошивок BIOS/UEFI (по умолчанию никогда не ставятся автоматически) |
| `--backup-dir DIR` | перед установкой сохранить копию текущих драйверов (`pnputil /export-driver`) |
| `--skip-restore-point` | не создавать точку восстановления |
| `-y` | не спрашивать подтверждения |
| `--save FILE` / `--from-file FILE` | сохранить снимок железа в файл или загрузить его из файла (для отладки и тестов) |

## Как программа решает, что нужно

| Группа | Когда | Пример объяснения |
|---|---|---|
| **НЕОБХОДИМО** | Устройство не работает из-за драйвера: в Диспетчере устройств ошибка с кодом 28, 10, 18, 31, 43, 52 и т.п. Или видеокарта работает на «Базовом видеоадаптере Microsoft» | «Видеокарта работает на базовом адаптере: нет аппаратного ускорения, игр, нормальной частоты обновления» |
| **РЕКОМЕНДУЕТСЯ** | Вышла новая версия драйвера для видеокарты, сети, Bluetooth или чипсета. Или вместо драйвера производителя стоит универсальный драйвер звука | «Сетевой драйвер напрямую связан с безопасностью и стабильностью подключения» |
| **НЕОБЯЗАТЕЛЬНО** | Устройство работает, а обновление даёт мало: звук, камера, контроллер дисков, USB, надстройки производителя, прошивки | «Работающий драйвер контроллера дисков лучше не менять без причины, от него зависит загрузка Windows» |
| **НЕ ТРЕБУЕТСЯ** | Драйвер в порядке, новее нет. Или используется стандартный драйвер Windows, и для этого класса устройств он правильный (USB, клавиатура, мышь, монитор) | «Используется стандартный драйвер Windows — это правильный выбор» |

Новизна определяется так же, как это делает сама Windows: сначала сравнивается дата драйвера, а при равной дате — номер версии.

По умолчанию ставятся только группы «необходимо» и «рекомендуется». Прошивки не ставятся никогда, если не указан `--allow-firmware`. Порядок установки: сначала чипсет, затем контроллеры дисков, видеокарта и сеть. Так советуют производители.

## Безопасность

- Скачивание — только с доменов Microsoft (`*.download.windowsupdate.com`, `download.microsoft.com`), NVIDIA (`*.download.nvidia.com`), AMD (`*.amd.com`), Intel (`*.intel.com`) и GitHub (обновление программы); остальные адреса отклоняются.
- Перед запуском/установкой проверяется подпись Authenticode нужного издателя (Microsoft / NVIDIA Corporation / Advanced Micro Devices / Intel Corporation). У `.cab` из каталога без подписи проверяются подписанные `.cat` внутри.
- Перед установкой — точка восстановления, по желанию резервная копия драйверов.
- Временные файлы удаляются в `finally`; из кэша Windows Update — только скачанное за сеанс.

## Структура

```
driverupdater/
  hardware.py              определение железа и драйверов (WMI/CIM через PowerShell)
  classify.py              правила «необходимо / рекомендуется / необязательно» и объяснения
  versions.py              сравнение версий и дат драйверов
  providers/windows_update.py  поиск, установка, очистка кэша через Windows Update Agent
  providers/catalog.py     поиск и скачивание из Microsoft Update Catalog
  providers/nvidia.py      свежий драйвер Game Ready с официального сайта NVIDIA
  providers/vendor_tools.py  официальные программы AMD и Intel (скачать, проверить, запустить, удалить)
  installer.py             точка восстановления, скачивание, проверка подписи, pnputil, перезапуск устройств
  vendors.py, ids.py       производители, их официальные сайты, названия моделей (pci.ids/usb.ids)
  names.py                 понятные названия: MSI вместо Micro-Star…, «Windows 11 Pro 25H2 · 64-бит»
  updater.py               обновление самой программы из GitHub Releases
  engine.py                общий сценарий «сканирование → поиск → оценка → план»
  report.py, cli.py        консольная версия
  webui/app.py             запуск окна (pywebview), проверка WebView2 (webui/webview2.py)
  webui/bridge.py          мост между интерфейсом и логикой: вызовы из JS и события в JS
  webui/web/               интерфейс: index.html, styles.css, app.js, icons.js
packaging/                 сборка exe (PyInstaller): DriverUpdater.spec, точки входа, сведения о версии
.github/workflows/build.yml  сборка exe на Windows и проверка на реальной системе
tests/                     тесты на снимке реального ПК (запускаются на любой ОС)
```

Тесты: `python -m unittest discover -s tests -t .`


## Ограничения

- Работает только в Windows 10/11 (x64). На других ОС — только режим `--from-file` для тестов.
- У Microsoft Update Catalog и сервиса NVIDIA нет документированного API: разбор проверяется вживую при каждой сборке (шаги «Live check» в GitHub Actions).
- У AMD и Intel нет открытого сервиса версий драйверов, поэтому для них запускаются их официальные программы, а не тихая установка.
- Exe не подписан сертификатом издателя: возможны предупреждения SmartScreen.
